### 4. `walking_distance_matrix.csv`

Symmetric 287 × 287 matrix of pairwise walking distances (in **metres**).

| Property | Value |
|----------|-------|
| Rows / columns | `cell_id` (0–286) |
| Units | metres |
| Average distance | **836.9 m** |
| Maximum distance | **3,351.1 m** |
| Diagonal | 0.0 (self-distance) |
| Algorithm | Dijkstra's shortest path on OSM walking network |
| Edge weights | `length` attribute (metres) from OpenStreetMap |
| Fallback | Euclidean × 1.3 for unreachable pairs |

**How distances are computed:**

1. The OSM pedestrian network (footpaths, sidewalks, roads) is downloaded for the ROI + 200 m buffer → 413 nodes, 1,078 edges.
2. Each cell centroid is snapped to its nearest network node.
3. Single-source Dijkstra from every unique snapped node gives shortest-path lengths.
4. The result is a real **walking distance** (not straight-line), suitable for pedestrian-reachability constraints.

## D. How to Use in MILP Modules (3.2–3.5)

### Notation mapping

| MILP symbol | Data source | Description |
|-------------|-------------|-------------|
| **m** | 287 | Number of demand zones |
| **p** | 287 | Number of candidate facility sites (every centroid is a candidate) |
| **i** | `cell_id` in `grid_centroids.geojson` | Demand zone index |
| **j** | `cell_id` in `candidate_locations.csv` | Candidate site index |
| **D_ij** | `walking_distance_matrix.csv[i][j]` | Walking distance from zone i to site j (metres) |
| **a_i** | `area_m2` in `candidate_locations.csv` | Area of demand zone i (use as weight proxy if needed) |

### Loading in Python

```python
import pandas as pd
import geopandas as gpd

# Distance matrix
D = pd.read_csv("grid_data/walking_distance_matrix.csv", index_col="from_cell")

# Candidate locations
candidates = pd.read_csv("grid_data/candidate_locations.csv")

# Grid cells and centroids as GeoDataFrames
cells = gpd.read_file("grid_data/grid_cells.geojson")
centroids = gpd.read_file("grid_data/grid_centroids.geojson")

# Example: distance from zone 10 to site 50
d_10_50 = D.loc[10, 50]
```

### Typical MILP usage

1. **Set cover / max-coverage**: Use D_ij with a coverage radius threshold (e.g., 200 m) to build the binary coverage matrix `a_ij = 1 if D_ij <= radius`.
2. **p-median**: Minimise total weighted distance `sum_i sum_j h_i * D_ij * x_ij` subject to facility count and assignment constraints.
3. **p-center**: Minimise the maximum distance any demand zone must travel to its assigned facility.
4. **Capacitated facility location**: Add capacity constraints per site using `area_m2` or external demand estimates.
